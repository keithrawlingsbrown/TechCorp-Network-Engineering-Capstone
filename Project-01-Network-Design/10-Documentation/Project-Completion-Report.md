## Challenges Overcome

### Challenge 1: Subnetting Complexity
**Issue:** Ensuring adequate IP addresses while maintaining simplicity  
**Solution:** Used /24 subnets, calculated requirements carefully  
**Learning:** Balance between simplicity and efficiency

### Challenge 2: VLAN Design Balance
**Issue:** Security vs. functionality trade-offs  
**Solution:** Department-based VLANs with firewall policies  
**Learning:** Security and usability can coexist

### Challenge 3: Packet Tracer Implementation
**Issue:** Complex topology in simulation tool  
**Solution:** Built incrementally, tested at each stage  
**Learning:** Modular approach works best

---

## Lessons Learned

1. **Requirements First:** Clear requirements make design easier
2. **Documentation Matters:** Good documentation saves time later
3. **Scalability Planning:** Always plan for growth
4. **Security Integration:** Security should be designed in, not added later
5. **Tool Proficiency:** Packet Tracer skills improve with practice
