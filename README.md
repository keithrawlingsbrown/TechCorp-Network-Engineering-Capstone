## Network Architecture

### Design Overview

**Network Type:** Enterprise LAN  
**Users:** 200 employees  
**Departments:** 6 (Management, IT, Sales, Engineering, Operations, Guest)  
**Architecture:** Hierarchical 3-Layer (Core, Distribution, Access)

### VLAN Design

| VLAN ID | Name | Subnet | Purpose |
|---------|------|--------|---------|
| 1 | Native | 192.168.1.0/24 | Default VLAN |
| 10 | Management | 192.168.10.0/24 | Network devices |
| 20 | Servers | 192.168.20.0/24 | Server infrastructure |
| 30 | Sales | 192.168.30.0/24 | Sales department |
| 40 | Engineering | 192.168.40.0/24 | Engineering department |
| 99 | Guest | 192.168.99.0/24 | Guest access |

### Topology

```
[Internet]
    |
[Router/Firewall]
    |
[Core Switch]
    |
[Distribution Switches]
    |
[Access Switches]
    |
[End Devices]
```

**Key Components:**
- 1 Core switch (high-speed backbone)
- 2 Distribution switches (redundancy)
- 6 Access switches (department connectivity)
- Router for inter-VLAN routing
- Firewall for security
